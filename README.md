# 🚀 Startup Funding Predictor

An AI-powered interactive dashboard designed to estimate venture capital funding amounts based on industry verticals, geographical locations, and investment structures. 

Built with Streamlit, this application provides data-driven market insights by analyzing historical startup funding trends to help entrepreneurs understand market benchmarks.

---

## 📊 Features

* **AI-Powered Estimates:** Get instant funding predictions based on real-world market metrics.
* **Granular Filters:** Adjust parameters dynamically by Industry Vertical, City Location, and Investment Type.
* **Market Insights Dashboard:** Interactive visual analytics mapping data across top startup hubs (Bangalore, Mumbai, New Delhi, etc.).
* **Dynamic Themes:** Toggle styles effortlessly using the integrated Control Panel (e.g., "Space Dark").

---

## 🤖 Machine Learning & Tech Stack

The predictive engine is built using a **Random Forest Regressor** model to handle the non-linear relationships and categorical variables across startup data.

* **Machine Learning Model:** Random Forest Regressor (`scikit-learn`)
* **Data Processing & Analysis:** Pandas, NumPy
* **Frontend/Dashboard:** Streamlit (Python)
* **Data Visualization:** Plotly / Altair
* **Deployment:** Streamlit Community Cloud
